kuber privacy policy

Last updated 4 November 2026.

kuber is a private tool with a single user, its author. Nobody else can sign in to it, and it does not collect data about anyone else.

What it accesses

With the author's consent, kuber uses Google's read-only Gmail scope (https://www.googleapis.com/auth/gmail.readonly). It only runs searches for emails that carry PDF statements from the author's banks, card issuers, depositories and pension provider, and downloads those PDF attachments. It cannot send, delete, move or label email, or mark it as read.

How the data is used and stored

Statements are read to work out account balances for the author's own financial planning. The PDFs and the balances taken from them are stored only on a server the author controls. The access token is stored there too, in a file only the kuber service can read, and it is kept out of backups.

Sharing

Gmail data is not sold, shared with third parties, used for advertising, or used to train AI models. kuber's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Downloaded statements can be deleted from the author's server.
